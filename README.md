# ワクワク合同会社 業務システム（wakuwaku-ai-system）

アーティスト **ai sayama** の制作時間を最大化するため、
事務・売上管理・商品管理・営業活動を段階的に自動化する社内システムです。

> **現在のステータス：Phase 0（設計・サンプルデータのみ）**
> プログラム実装・外部サービス接続はまだ行っていません。

## 基本方針

| # | ルール |
|---|---|
| 1 | 最初は **設計とサンプルデータのみ** で進める |
| 2 | 既存ファイル（Google Drive / Sheets / freee 等）を **変更・削除しない** |
| 3 | 認証情報・パスワードを **コードやリポジトリに保存しない** |
| 4 | 外部サービスへの接続は **事前に代表の承認** を得る |
| 5 | 会計データ（freee）は **読み取り専用** から開始する |
| 6 | メール送信・SNS投稿は **自動実行しない**（下書き作成まで） |
| 7 | **スタッフも使える** 構造（スプレッドシート中心・権限分離） |
| 8 | 将来の **Muse / ChatGPT 等 AI 連携** を前提にデータを構造化する |
