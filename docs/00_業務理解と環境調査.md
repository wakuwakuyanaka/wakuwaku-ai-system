## 5. 課題仮説（ai さんの時間を奪っているもの）

| 課題 | 現状の想定 | 自動化・仕組み化の方向 |
|---|---|---|
| 作品情報が散在 | 写真・サイズ・価格・所在がバラバラ | 作品台帳に一元化、画像は ID 命名で Drive 保存 |
| 在庫・委託先が分からない | 「あの作品どこ？」の確認が発生 | 所在ステータス管理、委託先一覧 |
| 請求・入金確認 | 手作業で freee と突合 | 売上台帳 ↔ freee 取引 ID の紐付け |
| 問い合わせ対応 | 毎回ゼロから返信 | テンプレート＋AI下書き（送信は人） |
| 海外営業が属人的 | 誰にいつ何を送ったか不明 | パイプライン管理、フォロー日リマインド |
| 経営数字が見えない | 月末に集計 | ダッシュボードで自動集計 |
| 制作時間が削られる | 事務が割り込む | **制作時間 KPI** をカレンダーから可視化 |
