# 02. 商品マスタ設計（作品台帳＋商品マスタ）

アート事業では「一点物の作品」と「量産品（グッズ）」の性質がまったく違うため、**2つの台帳に分けます**。

| 台帳 | 対象 | 単位 | 例 |
|---|---|---|---|
| **作品台帳（Artworks）** | 原画・一点物の立体作品・限定エディションの各個体 | 1点＝1行 | 油彩「〇〇」、原画だるま |
| **商品マスタ（Products）** | 量産グッズ・プリント・小だるま等 | 1 SKU＝1行（数量は在庫で管理） | ポストカード、ミニだるま |

---

### 作品ステータス

| コード | 表示名 | 意味 |
|---|---|---|
| `WIP` | 制作中 | まだ完成していない |
| `AVAILABLE` | 販売可 | 手元にあり販売可能 |
| `ON_DISPLAY` | 展示中 | 展示会に出品中（販売可） |
| `CONSIGNED` | 委託中 | ギャラリー等に委託中 |
| `RESERVED` | 商談中・取置 | 仮押さえ |
| `SOLD` | 売約済 | 売却済み |
| `NFS` | 非売品 | 手元に残す作品 |
| `COLLAB` | コラボ使用中 | 企業コラボで貸出・使用中 |
| `DONATED` / `LOST` | 寄贈／紛失・破損 | 例外処理 |

### SKU 命名規則

```
[事業区分]-[カテゴリ略号]-[品目]-[バリエーション]
 GD      - DRM         - MINI  - RED      → グッズ / だるま / ミニ / 赤
 GD      - PRT         - A4    - ART0031  → グッズ / プリント / A4 / 元作品0031
 CL      - XYZ         - TOTE  - BLK      → コラボ / コラボ先略号 / トート / 黒
```

## 3. 画像・ファイルの命名規則（Drive）

```
/作品画像/ART-2025-0031/
   ART-2025-0031_main.jpg        … メイン（Web・カタログ用）
   ART-2025-0031_detail_01.jpg   … ディテール
   ART-2025-0031_install.jpg     … 展示風景
   ART-2025-0031_raw/            … 撮影オリジナル（高解像度）
```
ID をファイル名の先頭に付けることで、AI・スクリプト・人の誰でも「どの作品の画像か」を一意に判断できます。

## 4. 将来の拡張
