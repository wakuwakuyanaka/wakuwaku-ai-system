# 03. 顧客・取引先データベース設計

「個人コレクター」と「法人（ギャラリー・卸先・コラボ企業・仕入先）」を **1つの取引先テーブル** で管理し、
法人の担当者は **担当者テーブル** に分けます（1社に複数担当者がいるため）。

```
 parties（取引先）1 ──── * contacts（担当者）
        │
        ├── * sales（売上）
        ├── * deals（海外営業案件）
        ├── * interactions（接触履歴：メール・面談・展示来場）
        └── * consignments（委託契約）
```

## 4. 個人情報の取扱い
- 顧客DBは **独立したスプレッドシート** にし、共有はスタッフ以上に限定。
- バイト・外部PDには、必要な列（発送先・法人名）のみを別シートで参照させる。
- AI 連携時は **氏名・メール・電話・住所をマスク** した書き出しを使用（→09）。
- 海外顧客（特に EU＝フランス）は GDPR を考慮し、同意取得・削除依頼に対応できるよう `opt_in_date` と `status` を管理。
