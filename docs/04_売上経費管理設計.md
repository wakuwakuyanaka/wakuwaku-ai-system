# 04. 売上・経費管理設計

## 1. freee との役割分担（最重要）

| | freee（会計） | 業務DB（Sheets） |
|---|---|---|
| 目的 | 税務・決算・請求書・入金 | 経営判断・作品別/チャネル別/国別分析 |
| 正（確定値） | **◎ 会計上の正** | 管理会計上の値（freee と突合） |
| 粒度 | 取引・仕訳 | 作品ID・SKU・案件ID・イベントID 単位 |
| 本システムからの操作 | **Phase 3 で読み取りのみ**。書き込みは当面しない | 読み書き |

```
 業務DB 売上台帳 ──(人が freee で請求書作成)──▶ freee 取引
        ▲                                         │
        └───── freee_deal_id で突合（読み取り API）──┘
                → 「入金済」「金額不一致」を自動判定
```

## 2. 売上台帳 `sales`

1明細＝1行（1回の取引で複数作品・商品が売れた場合は、同じ `order_id` で複数行）。

| 列名 | キー | 型 | 必須 | 説明 |
|---|---|---|---|---|
| 売上ID | sale_id | 文字 | ◎ | `SAL-2026-0105` |
| 注文ID | order_id | 文字 | ◎ | `ORD-2026-0088`（明細をまとめる） |
| 売上日（計上日） | sale_date | 日付 | ◎ | |
| 取引先ID | party_id | 文字 | ◎ | |
| 販売チャネル | channel | コード | ◎ | 直販／EC／展示会／委託／卸／コラボ／ライセンス／制作依頼 |
| 事業ライン | business_line | コード | ◎ | A〜G（→00） |
| 国 | country_code | コード | ◎ | 販売先の国 |
| 作品ID or SKU | item_id | 文字 | ◎ | `ART-...` または `GD-...` |
| 数量 | qty | 数値 | ◎ | 作品は 1 |
| 単価（取引通貨） | unit_price | 数値 | ◎ | |
| 通貨 | currency | コード | ◎ | JPY/TWD/EUR/USD |
| 為替レート | fx_rate | 数値 | ◎ | 為替表から自動参照 |
| 売上額（JPY・税抜） | amount_jpy | 数値 | 自動 | |
| 消費税区分 | tax_type | コード | ◎ | 課税10%／軽減8%／輸出免税／不課税 |
| 手数料（委託・決済） | fee_jpy | 数値 | | ギャラリー手数料、カード手数料 |
| 送料・関税（自社負担） | shipping_cost_jpy | 数値 | | |
| 原価 | cogs_jpy | 数値 | 自動 | 作品台帳・商品マスタから |
| 粗利 | gross_profit_jpy | 数値 | 自動 | 売上−原価−手数料−送料 |
| イベントID | event_id | 文字 | | 展示会での売上 |
| 案件ID | deal_id | 文字 | | 海外営業・コラボ案件 |
| 支払期日 | due_date | 日付 | | |
| 入金状況 | payment_status | コード | ◎ | 未請求／請求済／入金済／一部入金／キャンセル |
| freee 取引ID | freee_deal_id | 文字 | | 突合キー |
| 担当 | staff | コード | | |
| 備考 | notes | 長文 | | |

## 3. 経費台帳 `expenses`

freee が経費の正。業務DBでは **「作品・イベント・案件ごとの費用」** を把握するために記録します。

| 列名 | キー | 説明 |
|---|---|---|
| 経費ID | expense_id | `EXP-2026-0201` |
| 日付 | date | |
| 支払先 | party_id / payee | |
| 勘定科目 | account_code | freee の勘定科目名に合わせる（画材費＝仕入高 or 消耗品費 等は税理士と確認） |
| 費用区分 | cost_category | 画材／額装／製造／梱包・送料／出展料／旅費交通費／広告宣伝／外注／通信・SaaS／その他 |
| 金額（税込） | amount | |
| 通貨・為替・円換算 | currency / fx_rate / amount_jpy | 海外出展費用など |
| 紐付け先 | link_type / link_id | 作品 ART- ／イベント EVT- ／案件 DEAL- ／コラボ COL- |
| 支払方法 | payment_method | 法人カード／振込／立替（スタッフ名） |
| 領収書 | receipt_url | Drive の PDF リンク（freee にも登録） |
| freee 取引ID | freee_deal_id | 突合キー |
| 登録者 | recorded_by | |

## 4. 為替レート表 `fx_rates`

| 列名 | 説明 |
|---|---|
| 月 | 2026-11 |
| 通貨 | TWD / EUR / USD |
| レート（1通貨＝円） | 月初の TTM 等、社内ルールで統一 |
| 出典 | 手入力（Phase 1）／API（将来・承認後） |

> 会計上の換算ルールは税理士と合わせること。業務DBの円換算は「管理用の概算」と位置づけます。

## 5. 主な集計（自動化対象）
- 月次売上・粗利（チャネル別／事業ライン別／国別）
- 作品単価の推移、シリーズ別売上
- イベント別収支（売上 − 出展料・旅費・送料）
- 売掛金一覧（請求済・未入金、期日超過アラート）
- freee との差異レポート（業務DBにあって freee にない取引、またはその逆）
