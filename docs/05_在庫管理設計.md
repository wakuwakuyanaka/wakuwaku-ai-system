# 05. 在庫管理設計

## 1. 考え方

| 対象 | 管理方法 |
|---|---|
| 作品（一点物） | 作品台帳の **`location_code`（所在）＋ `status`** で管理。数量概念なし |
| 商品（SKU） | **拠点別在庫数** を「入出庫履歴の合計」で算出 |

在庫数は直接書き換えず、**入出庫履歴（トランザクション）を積み上げて計算**します。
→ 誰が・いつ・なぜ在庫を動かしたか後から追跡でき、棚卸差異の原因も分かります。

## 2. 拠点マスタ `locations`

| 拠点コード | 名称 | 区分 | 自社資産か |
|---|---|---|---|
| `LOC-ATELIER` | アトリエ（台東区） | 自社 | ○ |
| `LOC-STOCK` | 倉庫・保管場所 | 自社 | ○ |
| `LOC-GAL-JP01` | 国内ギャラリーA（委託） | 委託先 | ○（委託在庫） |
| `LOC-GAL-TW01` | 台湾ギャラリーB（委託） | 委託先 | ○（委託在庫） |
| `LOC-SHOP-JP01` | 国内雑貨店C（委託） | 委託先 | ○ |
| `LOC-EVENT` | 展示会・イベント会場（一時） | 一時 | ○ |
| `LOC-TRANSIT` | 輸送中 | 一時 | ○ |
| `LOC-COLLAB` | コラボ先に貸出中 | 貸出 | ○ |

## 3. 入出庫履歴 `stock_movements`

| 列名 | キー | 説明 |
|---|---|---|
| 移動ID | movement_id | `MOV-2026-0301` |
| 日付 | date | |
| 対象 | item_id | SKU または 作品ID |
| 数量 | qty | 作品は 1 |
| 移動元 | from_location | 入荷時は `SUPPLIER` |
| 移動先 | to_location | 販売時は `CUSTOMER` |
| 種別 | movement_type | 入荷／販売出庫／委託出し／委託戻り／展示搬入／展示搬出／サンプル・贈答／破損・廃棄／棚卸調整 |
| 関連ID | ref_id | 売上ID・イベントID・委託契約ID |
| 実施者 | staff | |
| 備考 | notes | |

### 拠点別在庫（自動計算ビュー）`stock_levels`
```
在庫数(SKU, 拠点) = Σ 入庫(to_location=拠点) − Σ 出庫(from_location=拠点)
```
| SKU | 拠点 | 在庫数 | 発注点 | アラート |
|---|---|---|---|---|
| GD-DRM-MINI-RED | LOC-STOCK | 12 | 20 | ⚠ 要発注 |

## 4. 委託管理 `consignments`

ギャラリー・店舗に預けている作品/商品と精算を管理します。

| 列名 | 説明 |
|---|---|
| 委託ID | `CSG-2026-0004` |
| 委託先 | 取引先ID（`ORG-...`）＋ 拠点コード |
| 開始日／終了予定日 | |
| 手数料率 | 例 40% |
| 精算サイクル | 月末締め翌月20日 等 |
| 対象品リスト | 作品ID・SKU と数量（明細は入出庫履歴で管理） |
| 契約書 | Drive リンク |
| 状態 | 委託中／精算待ち／終了 |

**月次の委託精算フロー**
1. 委託先から販売報告を受領（メール・PDF）
2. 売上台帳に登録（channel=委託、fee=手数料）
3. 入出庫履歴に「委託先 → CUSTOMER」を記録
4. 期日に精算額の入金を freee で確認

## 5. 棚卸
- 年1回（決算前）＋ 半期に1回の実地棚卸を推奨
- 棚卸シートに実数を入力 → 差異を `棚卸調整` として入出庫履歴に記録
- 作品は **写真付き所在確認リスト** を出力して確認（バイトでも作業可能）

## 6. 展示会の搬入出チェック
イベントごとに「出品リスト」を作品台帳・商品マスタから作成 →
搬入時（`展示搬入`）・搬出時（`展示搬出`）に一括で入出庫登録。売れたものだけ `販売出庫` に変える。
