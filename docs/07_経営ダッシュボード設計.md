# 07. 経営ダッシュボード設計

## 1. 目的
ai さんが **月に数分見るだけで経営状況が分かる** こと。
集計作業をなくし、判断（何を作るか・どこに売るか）に集中できるようにする。

## 2. 利用者別の画面

| 画面 | 利用者 | 更新頻度 | 主な問い |
|---|---|---|---|
| ① 経営サマリー | ai／外部PD | 月次（自動） | 今月・今期は順調か？ |
| ② 売上分析 | ai／スタッフ | 週次 | 何が・どこで・誰に売れているか？ |
| ③ 在庫・作品所在 | スタッフ | 随時 | 何がどこにいくつあるか？ |
| ④ 営業パイプライン | ai／スタッフ／外部PD | 週次 | 海外展開は進んでいるか？ |
| ⑤ 今週のToDo | 全員 | 毎日 | 今日やるべきことは？ |
| ⑥ 制作時間モニター | ai | 週次 | 制作時間は確保できているか？ |

## 3. KPI 一覧

### ① 経営サマリー
| KPI | 定義 | データ元 |
|---|---|---|
| 月次売上（税抜・円） | Σ amount_jpy | sales |
| 前年同月比／予算比 | | sales, budget |
| 粗利・粗利率 | Σ gross_profit / Σ amount | sales |
| 営業利益（概算） | freee の損益（読み取り） | freee |
| 現預金残高 | freee の口座残高（読み取り） | freee |
| 売掛金残高・期日超過 | 未入金の請求額 | sales |
| 海外売上比率 | 国≠JP の売上 / 全売上 | sales |

### ② 売上分析
- 事業ライン別（原画／グッズ／卸／委託／展示／コラボ）月次推移
- 国別売上（JP / TW / FR / US）
- シリーズ別・作品価格帯別の売上
- 顧客ランク別売上、リピート率、新規顧客数
- イベント別収支

### ③ 在庫・作品所在
- 作品ステータス別件数（販売可／委託中／展示中／売約済）
- 拠点別の作品数・在庫評価額
- 発注点割れ SKU 一覧
- 長期滞留（委託180日超など）

### ④ 営業パイプライン
- ステージ別の案件数と加重見込額（国別）
- 今月の新規リード数／成約数／成約率
- 次回期日超過の案件一覧

### ⑥ 制作時間モニター（このシステムの最重要 KPI）
| KPI | 定義 | データ元 |
|---|---|---|
| 週の制作時間 | カレンダーで「制作」カテゴリ（例：色＝赤 or タイトル先頭 `[制作]`）の合計時間 | Google Calendar（読み取り） |
| 制作時間比率 | 制作時間 ÷ 稼働時間 | Calendar |
| ai さんの事務時間 | `[事務]` `[打合せ]` の合計 | Calendar |
| 自動化で削減した時間（推計） | 自動化タスクの回数 × 1回あたりの削減分 | 運用ログ |

> 目標例：制作時間比率 60% 以上（現状値を Phase 1 で計測してから設定）

## 5. 実装方針
- Phase 1：Google Sheets の「ダッシュボード」シート（QUERY / SUMIFS / ピボット）
- Phase 2：Looker Studio（無料）で見やすく、外部PDには閲覧リンクのみ共有
- Phase 3：freee（読み取り）・Calendar（読み取り）の数値を追加
- 予算表 `budget`（月×事業ライン×国）を別途用意し、予実比較
