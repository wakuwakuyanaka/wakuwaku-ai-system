## Phase 1：Google Sheets で運用開始（手入力でまず回す）
**ゴール：データが1か所に集まり、スタッフが入力できる状態**
1. Drive に新規フォルダ `ワクワク業務システム/` を作成（既存フォルダには触れない）🔐
2. 新規スプレッドシートを作成：作品台帳／商品マスタ／顧客DB／売上・経費／在庫／海外営業／コード表
3. プルダウン（データ入力規則）・保護範囲・共有権限を設定
4. 既存リストからの **コピー移行**（元ファイルは変更しない）
5. スタッフ向け入力マニュアル（1枚もの）
6. 簡易ダッシュボード（関数のみ）
7. 制作時間の現状計測開始（カレンダーの付け方ルールを決める）

**完了基準**：1か月分の売上・在庫・案件が新システムで管理できている

## Phase 2：自動化（Google Apps Script）
**ゴール：転記・集計・リマインドの手作業をなくす**
| 機能 | 内容 |
|---|---|
| ID 自動採番 | 新規行に `ART-` `SAL-` 等を自動付与 |
| 自動計算 | 円換算、粗利、在庫数、顧客の累計購入額 |
| リマインド | 次回フォロー日・支払期日・発注点割れを **自分宛て** に通知（チャット or 自分宛てメール）|
| 出品リスト／作品リスト PDF | 展示会用・営業用を作品台帳から生成 |
| Looker Studio ダッシュボード | 外部PD 共有用 |
| 変更ログ | 誰がいつ何を変えたかを記録 |

## Phase 3：会計・カレンダー連携（読み取り専用）🔐
| 機能 | 内容 |
|---|---|
| freee 読み取り連携 | 取引・入金・口座残高・試算表を取得 → 売上台帳と突合 |
| 差異レポート | 未登録・金額不一致・未入金を一覧化 |
| Calendar 読み取り | 制作時間 KPI、展示・納期の自動一覧 |
| Gmail（読み取り・ラベル） | 問い合わせメールの一覧化（本文は保存せずリンク） |

**freee への書き込み（請求書の自動作成等）は Phase 3 の運用が安定してから、別途承認**

## Phase 4：AI アシスト（ChatGPT / Muse 等）🔐
| 機能 | 人の役割 |
|---|---|
| 作品キャプション・商品説明の多言語下書き（英・仏・繁体字） | 確認・修正して採用 |
| 問い合わせ返信・海外営業フォローの **下書き** | 確認して **人が送信** |
| SNS 投稿文の **下書き**（作品台帳から） | 確認して **人が投稿** |
| 月次レポートの文章化・示唆出し | 経営判断は人 |
| データへの自然言語質問（「台湾で一番売れたシリーズは？」） | 回答を確認 |
