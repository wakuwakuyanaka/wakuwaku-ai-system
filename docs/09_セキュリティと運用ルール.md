# 09. セキュリティと運用ルール

## 1. 認証情報の取り扱い
| ルール | 具体策 |
|---|---|
| パスワード・APIキーをコード・リポジトリ・スプレッドシートに書かない | GAS は「スクリプトプロパティ」、ローカルは Mac のキーチェーン or `.env`（`.gitignore` 済み） |
| OAuth は最小スコープ | freee は読み取りスコープから。Google は対象ファイルのみに限定（`drive.file` スコープ優先） |
| 共有アカウントを使わない | スタッフは各自の Google アカウントで権限付与 |
| 退職・契約終了時 | 共有解除チェックリストを実施 |
| 2段階認証 | Google・freee・Zoho 全アカウントで必須 |

## 2. 承認フロー（外部接続・本番操作）

| 操作 | 承認者 | 記録 |
|---|---|---|
| 外部サービスへの新規接続（API 連携・コネクタ） | ai sayama | 承認ログ（docs/approvals/） |
| 既存ファイルの読み取り調査 | ai sayama | 同上 |
| 新規ファイル・フォルダの作成 | ai sayama（Phase 1 開始時に一括） | 同上 |
| 既存ファイルの変更・削除 | **行わない**（必要な場合は都度承認＋バックアップ） | 同上 |
| freee への書き込み | ai sayama ＋ 税理士相談 | 同上 |
| メール送信・SNS 投稿 | **自動実行しない**。人が送信ボタンを押す | ― |

## 3. 自動化の安全レベル

| レベル | 内容 | 例 | 許可 |
|---|---|---|---|
| L0 | 読み取り・集計 | ダッシュボード、差異レポート | Phase 2〜 |
| L1 | 社内向け通知 | 自分宛てリマインド | Phase 2〜 |
| L2 | 下書き作成 | メール下書き、投稿文案 | Phase 4〜（人が確認） |
| L3 | 社内データ書き込み | ID 採番、在庫計算 | Phase 2〜（ログ必須） |
| L4 | 外部への送信・会計登録 | メール送信、SNS 投稿、freee 登録 | **当面禁止** |

## 4. AI（ChatGPT / Muse 等）連携ルール
- AI に渡すデータは **マスク済みエクスポート** を使う（顧客の氏名・メール・電話・住所を ID に置換）
- 未発表作品・契約条件・価格交渉中の情報は、AI サービスの学習利用設定（オプトアウト）を確認してから扱う
- AI の出力は **必ず人が確認**。価格・契約・会計に関する判断は AI に任せない
- 使うプロンプトは `ai/prompts/` に保存し、スタッフ全員が同じ品質で使えるようにする
- データ受け渡し形式：CSV / JSON（列名は 11_データ辞書 のキー名＝英語スネークケースで統一）

## 5. バックアップ
- Sheets：月1回、`99_アーカイブ/` に日付付きコピー（Phase 2 で自動化）
- 版の履歴：Google の版履歴を併用
- freee：会計データは freee 側で保管、月次で試算表 PDF を Drive に保存

## 6. 個人情報・海外法規
- 顧客の個人情報は顧客DBファイルに集約し、共有範囲を限定
- EU 顧客（フランス）は GDPR に配慮：同意記録・削除依頼対応
- 具体的な法的対応は専門家に確認すること
