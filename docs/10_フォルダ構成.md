# 10. フォルダ構成案

## 1. このリポジトリ（設計書・スクリプト・テンプレートの管理）

```
wakuwaku-ai-system/
├── README.md                     … 全体概要・基本ルール
├── .gitignore                    … 認証情報・個人データを除外
├── docs/                         … 設計書（本ドキュメント群）
│   ├── 00〜11_*.md
│   └── approvals/                … 承認記録（外部接続・Phase 開始）
├── sample_data/                  … 架空のサンプルデータ（CSV）
├── schemas/                      … テーブル定義（将来：JSON Schema。AI・GAS 共通）
├── apps_script/                  … (Phase 2) Google Apps Script のソース
│   ├── common/                   …   ID 採番・ログ・設定読込
│   ├── inventory/
│   ├── sales/
│   └── reminders/
├── integrations/                 … (Phase 3) 外部連携
│   ├── freee/                    …   読み取り専用クライアント
│   ├── google_calendar/
│   └── gmail/
├── ai/                           … (Phase 4) AI 連携
│   ├── prompts/                  …   キャプション・返信下書き・翻訳等のプロンプト
│   └── exports/                  …   マスク済みデータ書き出し定義（実データは置かない）
├── templates/                    … 請求書・作品証明書・インボイス・提案書のひな形
└── manuals/                      … スタッフ向け操作マニュアル
```

※ 実データ（顧客情報・売上実績）は **リポジトリに置かず Google Drive に保管** します。

## 2. Google Drive（業務データの保管場所）

**既存フォルダには手を加えず**、新しく `ワクワク業務システム/` を作る案です。

```
ワクワク業務システム/
├── 00_ダッシュボード/
│   └── 経営ダッシュボード（Sheets / Looker Studio）
├── 01_マスタ/
│   ├── 作品台帳                  … artworks
│   ├── 商品マスタ                … products
│   └── コード表                  … 拠点・カテゴリ・ステータス等
├── 02_顧客・取引先/               … 🔒 スタッフ以上のみ
│   ├── 顧客DB                    … parties / contacts / interactions
│   └── 契約書/
├── 03_売上・経費/                 … 🔒 スタッフ以上のみ
│   ├── 売上経費台帳              … sales / expenses / fx_rates / budget
│   └── 領収書/ （年/月）
├── 04_在庫/
│   ├── 在庫管理                  … locations / stock_movements / consignments
│   └── 棚卸記録/
├── 05_海外営業/                   … 外部PD と共有
│   ├── 営業パイプライン          … deals / markets / art_fairs
│   ├── 台湾/ フランス/ アメリカ/
│   └── ポートフォリオ（多言語）/
├── 06_展示・イベント/
│   └── EVT-2026-001_〇〇展/      … 出品リスト・搬入資料・写真
├── 07_コラボ/
│   └── COL-2026-001_〇〇社/
├── 08_作品画像/
│   └── ART-2025-0031/            … ID 単位のフォルダ
├── 09_テンプレート/
├── 10_マニュアル/
└── 99_アーカイブ/                 … 月次バックアップ
```

### スプレッドシートを分ける理由
1ファイルに全部入れると「バイトに見せたくない顧客情報・売上」まで見えてしまうため、
**共有範囲の異なる単位でファイルを分割** し、必要な列だけ `IMPORTRANGE` で参照します。

- 高解像度の撮影データのみ外付けSSD＋Drive の二重保管を推奨
