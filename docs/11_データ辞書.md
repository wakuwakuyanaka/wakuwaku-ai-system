# 11. データ辞書（ID体系・コード値）

AI・スクリプト・スタッフが同じ意味でデータを扱うための共通辞書です。
列のキー名は **英語スネークケース**、画面の表示名は日本語で統一します。

## 1. ID 体系

| 接頭辞 | 対象 | 形式 | 例 |
|---|---|---|---|
| ART | 作品 | ART-制作年-連番4桁 | ART-2025-0031 |
| (SKU) | 商品 | 区分-カテゴリ-品目-バリエーション | GD-DRM-MINI-RED |
| CUS | 個人顧客 | CUS-連番4桁 | CUS-0001 |
| ORG | 法人取引先 | ORG-連番4桁 | ORG-0012 |
| SUP | 仕入先・製造 | SUP-連番4桁 | SUP-0003 |
| CON | 担当者 | CON-連番4桁 | CON-0040 |
| INT | 接触履歴 | INT-年-連番 | INT-2026-0001 |
| ORD / SAL | 注文 / 売上明細 | ORD-年-連番 / SAL-年-連番 | SAL-2026-0105 |
| EXP | 経費 | EXP-年-連番 | EXP-2026-0201 |
| MOV | 入出庫 | MOV-年-連番 | MOV-2026-0301 |
| CSG | 委託契約 | CSG-年-連番 | CSG-2026-0004 |
| DEAL | 営業案件 | DEAL-年-連番 | DEAL-2026-0012 |
| EVT | 展示・イベント | EVT-年-連番 | EVT-2026-001 |
| COL | コラボ案件 | COL-年-連番 | COL-2026-001 |
| LOC | 拠点 | LOC-名称 | LOC-GAL-TW01 |

**ルール**：ID は一度振ったら変更・再利用しない。削除せず `status` で無効化する。
